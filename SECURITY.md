# Relato de vulnerabilidades

Não publique senhas, tokens, documentos pessoais, localizações ou detalhes de uma vulnerabilidade em uma issue pública.

Se encontrar uma falha de segurança, use a opção **Report a vulnerability** na aba **Security** do repositório. Inclua somente os passos necessários para reproduzir o problema e remova dados pessoais dos exemplos.

O projeto mantém suporte de segurança apenas para a versão atual da branch `main`.
